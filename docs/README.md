# docs/ — kaart

```
docs/
  plans/                 verandering: wat er nog moet gebeuren
    TODO.md              hét nu-document: claimbord + open werk + recently done
    HANDOFF.md           wegwerp-opdracht voor de eerstvolgende sessie
    briefs/              uitvoerbare briefs, één bestand per onderwerp
    done/                register.md (gesloten nummers) + decisions.md (genomen beslissingen)
    _reconcile/          drift-log.md: housekeeping-ledger
  reference/             hoe het werkt: beschrijft wat ís, niet wat verandert
```
